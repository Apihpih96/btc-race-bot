A BTC trading bot for make.fun's 24-hour race: it buys cbBTC/USDC dips below the 90-bar mean and sells the reversion, with a stop-loss and a cooldown after a stop-out. Paper money only; nothing is traded for real.

## Run it

```sh
node main.ts
```
